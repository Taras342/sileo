Репозиторий для Sileo

Здесь лежат твики «Анимация разблокировки», «Неофетч» и «Комната». На телефоне их ставят ссылкой, файл отдельно перекидывать не нужно.

Sileo → Источники → «+» → вставь эту ссылку:

https://taras342.github.io/sileo/

  1. Нажми «Добавить источник» и дождись обновления.
  2. Открой нужный пакет и установи его. «Комната» 1.4.0 хранит для каждого приложения, на каком столе оно будет. Иконки пока не меняет.
  3. Когда Sileo спросит про перезапуск SpringBoard, согласись.
  4. Настройки → Анимация разблокировки. Заблокируй телефон и открой его.

Нужен уже установленный palera1n и Sileo на iPhone X или старше. Репозиторий публичный: по ссылке можно только скачать этот твик.
